# 网课学习助手

可配置的 Electron 桌面工具，支持智慧树与学习通。小窗默认置顶、课程默认静音，每门课程分别保存进度，同一平台共享本应用内的登录会话。

新增 **中国大学 MOOC 视频续播试用适配**：复用平台原生“自动播放下一视频”，提供 1 倍速静音播放、暂停恢复、卡顿停止和独立本地观察记录。模拟页面和单门真实课程的连续切换已验证，全课流程仍待验收。暂不处理该平台文档、测验、考试或平台完成判定。见 [MOOC 使用与限制](docs/mooc-support.md)。

首版以 **Windows + Node.js 24** 为验收环境。MIT 开源，提供源码，暂不提供安装包；不是平台官方客户端。

## 安装与启动

```sh
git clone https://github.com/y09749204-gif/course-study-assistant.git
cd course-study-assistant
npm ci
npm start
```

Electron 运行时需要网络下载，首次启动下载失败请检查网络后重试。Windows 也可双击 `start-course-assistant.cmd`，先确保运行时已安装。运行不依赖 Codex 桌面窗口保持打开。

首次启动进入课程配置，没有预置真实课程。编辑两个未配置的平台占位项，或点击“新增课程”：填写名称、平台、已登录后复制的官方课程学习页面链接。智慧树可配置每日新完成小节数、正常播放分钟数及可选成绩分析链接；学习通需填写目录总章数。保存后返回学习页，在课程页面登录，再开始任务。

## 使用与支持范围

- 图钉可取消置顶，课程预览可展开。正常视频播放、章节切换、当前学习通 PDF 阅读器浏览与完成确认、可识别的测验题型均有模拟测试。特殊文档和网站改版可能需要适配。
- AI 默认关闭，在设置中启用。学习通 AI 失败或题目无法识别时暂停；智慧树弹题沿用有效选项随机兜底行为。格式校验通过不代表答案正确。
- 暂停会停止任务操作；登录、验证码和无法判定的内容需要人工处理。前台需求取决于具体操作及平台，置顶不代表所有动作均可后台执行。
- 切换课程会暂停并关闭当前视图。提交尚待平台确认时先核对，避免重复提交。完成情况以平台标记为准，不伪造时长或任务点。
- 自动运行默认关闭，需要应用持续运行。智慧树自动检查使用上海时间每日 06:00；学习通可在智慧树任务后继续当前所选课程。

使用前确认课程及平台允许的辅助方式。本工具不能保证平台计分或替代实际学习。

## AI 与可选依赖

见 [AI 配置](docs/ai-setup.md)。兼容接口使用自行配置的服务、模型和 API Key，费用及限额以提供方为准。本地 Codex 模式调用自行安装并登录的官方客户端，不分发认证凭据。

学习通替换字体题目可能需要本地 OCR，先安装 Python，再执行：

```sh
python -m pip install -r requirements-ocr.txt
```

OCR 通过 `python` 命令处理当前题目截图，不捆绑个人字体或教材。模型及推理组件属于外部可选依赖。[REA 诊断](docs/rea-diagnostics.md)也是可选项，普通启动不开放调试端口，不自动下载 REA。

## 数据与隐私

`npm start` 和 Windows 入口使用系统应用数据目录下的 **`course-study-assistant`**，Windows 通常为 `%APPDATA%\course-study-assistant`。`npm run dev` 或直接 `electron .` 使用源码目录的 `.local-data/development`。测试使用独立临时目录，`ZH_STUDY_TEST_DATA_DIR` 必须为绝对路径，不能指向公开版运行目录、旧个人版或团队应用数据。

课程链接、保存的 Cookie、会话备份和 API Key 使用系统安全存储加密；学习状态和部分配置为本地明文，浏览器也会保存本地会话数据。加密不可用时拒绝保存秘密配置。不要上传数据目录、浏览器档案或诊断原文。

启用 AI 后会向所选服务发送题目及选项。Codex 自行管理认证。隐私扫描检查常见秘密、私密路径和运行文件，仍需人工审查，无法保证检出所有信息。

## 开发与测试

```sh
npm ci
npm run test:browser:install
npm run build:preload
npm run check:generated
npm run check:privacy
npm test
npm run dev
```

浏览器测试默认使用 Playwright Chromium，可通过本地 `CHROME_EXECUTABLE` 指定现有浏览器；`ELECTRON_EXECUTABLE` 可指定测试运行时，路径不提交。测试使用模拟课程和隔离数据，不登录真实平台或调用付费 AI。REA 集成测试需显式本地配置，默认跳过。

## 故障排查与卸载

下载失败先检查网络与代理。AI 超时核对服务、模型、登录及限额，保留待确认提交。目标被遮挡时展开课程检查弹层、滚动裁剪和缩放。平台未确认完成时检查目录，不以本地状态代替成绩。网站改版请提供脱敏复现步骤。

退出应用后可以移除源码。清除本机记录前先备份，仅删除确认过的 `course-study-assistant` 数据目录；Codex 认证和其他应用数据单独管理。
