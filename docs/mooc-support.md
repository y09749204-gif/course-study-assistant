# 中国大学 MOOC 视频续播（试用）

## 添加课程

1. 打开设置 → 课程配置 → 新增课程。
2. 平台选择“中国大学 MOOC”，填写名称和官网登录后的课程学习页面链接。
3. 链接需包含 `/mooc/learn/…/content/…` 路径和 `tid` 学期参数。课程和学期共同决定记录身份；修改学期需新增课程，同一课程内切换单元不重置记录。
4. 返回学习，打开课程，在助手内完成登录。Chrome 的登录状态不会复制到助手。
5. 在课程页勾选平台自带的“自动播放下一视频”，点击助手“开始”。

## 播放与记录

- 助手以 1 倍速静音播放当前唯一的视频。自然结束后的跳转由平台处理；不改写播放进度、不请求隐藏进度接口、不伪造平台完成记录。
- 平台在同一页或新页面切换单元时，助手跟随当前课程和学期。
- “观察到播完”记录助手观察到的自然结束，不等于平台确认完成；“正常播放”只累计相邻有效采样的正常播放时间，不计快进或长时间挂起。
- 视频加载或卡顿超过 30 秒、媒体错误、找不到唯一播放器、平台未继续下一段时停止，保留可展开的原因。检查课程后点击“恢复”。
- 暂停、结束、关闭视图及切换到其他课程会停止当前播放。应用退出后不会自行恢复 MOOC 播放。
- 重新打开课程时回到本地最近观察到的单元，播放位置仍由平台恢复；助手不会通过设置时间进行跳转。
- 本轮没有全课完成判定，不会显示“平台已完成”。每日目标与次日成绩核对只适用于原有平台。

## 数据和支持边界

- MOOC 使用独立的 `persist:icourse` 浏览器会话分区。链接由系统安全存储加密保存；每门课程的本地观察在其独立 `courses/<随机ID>/icourse-study/state.json` 下。
- 不读取其他浏览器 Cookie，不分发账号和预置真实课程链接。开发、模拟测试使用隔离数据目录。
- 登录、验证码、认证学习购买、文档、讨论、测验和考试需要用户处理；不会自动接受协议或购买认证。
- 自动续播依赖官网自带开关及其目录行为。跨域播放器、页面改版和自然结束后的完成标记尚需实机验收；不保证平台计分。
- 模拟测试覆盖自然续播、暂停恢复、切换、视图边界、过期消息、快进不计时和无下一段时停止。单门真实课程已验证平台连续切换视频和正常播放计时；全课流程、跨域播放器及其他课程尚待验收，按试用功能使用。
